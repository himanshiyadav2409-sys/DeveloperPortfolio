## Binary Number Representation

### 1. Decimal to Binary Conversion

Convert decimal number 75 into binary using repeated division by 2.

75 ÷ 2 = 37 remainder 1

37 ÷ 2 = 18 remainder 1

18 ÷ 2 = 9 remainder 0

9 ÷ 2 = 4 remainder 1

4 ÷ 2 = 2 remainder 0

2 ÷ 2 = 1 remainder 0

1 ÷ 2 = 0 remainder 1

Reading the remainders from bottom to top:

**75 (Decimal) = 1001011 (Binary)**

### 2. Binary to Decimal Conversion

Convert binary number 110101 into decimal using the positional weight method.

= (1 × 2⁵) + (1 × 2⁴) + (0 × 2³) + (1 × 2²) + (0 × 2¹) + (1 × 2⁰)

= 32 + 16 + 0 + 4 + 0 + 1

= **53**

Therefore, **110101 (Binary) = 53 (Decimal)**.

### 3. Why Computers Use Binary

Computers use binary internally because electronic circuits can easily represent two states, ON (1) and OFF (0), making it reliable for processing and storing information.
